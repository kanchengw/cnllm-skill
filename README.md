# CNLLM Skill

Claude Skill for [CNLLM](https://github.com/kanchengw/cnllm) – a unified adapter for Chinese LLMs (DeepSeek, GLM, Qwen, etc.).

## Install

```bash
npx skills add kanchengwcnllm-skill
```

## Contents

SKILL.md – skill instructions for agents

examples – runnable usage examples (fallback, async, LangChain, batch)

references – additional reference files
